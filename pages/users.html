Users

Rows load from Firestore learner profiles (users/{uid} by default, or userProfiles / others if users is empty). Remove from directory soft-deletes the profile so it disappears here and from dashboard counts. Firebase Authentication is separate: deleting only in Auth can leave an orphan profile here; removing only here does not delete the sign-in account — use Firebase Console → Authentication for that (works on the Spark plan).
